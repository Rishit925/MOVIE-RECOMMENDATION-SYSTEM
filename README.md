# MOVIE-RECOMMENDATION-SYSTEM
# 🎬 Movie Recommendation System

## Overview

This project implements a content-based movie recommendation system using the TMDB 5000 Movies Dataset. The recommendation engine suggests movies that are similar to a selected movie by analyzing metadata such as genres, keywords, cast, crew, and movie overview.

The project demonstrates the complete workflow of building a recommendation system, including data preprocessing, feature engineering, text vectorization, and similarity-based recommendations.

## Dataset

The project uses two datasets:

* **tmdb_5000_movies.csv**
* **tmdb_5000_credits.csv**

These datasets contain detailed information about movies, including:

* Title
* Genres
* Keywords
* Cast
* Crew
* Overview
* Popularity
* Vote Average

## Project Workflow

### 1. Data Preparation

The movie and credits datasets were merged using the movie title to create a single dataset containing all relevant information.

The dataset was then explored to understand its structure and identify the required features for building the recommendation system.

---

### 2. Data Cleaning

Several preprocessing steps were performed before generating recommendations.

* Selected only the required columns.
* Removed rows containing missing values.
* Removed duplicate records.
* Converted JSON-like string columns into Python lists.
* Extracted useful information from nested data structures.

---

### 3. Feature Engineering

Relevant movie information was combined into a single text feature called **tags**.

The tags include information from:

* Genres
* Keywords
* Cast
* Director
* Movie Overview

These combined features provide a better representation of each movie for similarity comparison.

---

### 4. Text Preprocessing

Before vectorization, the text data was cleaned using:

* Lowercase conversion
* Tokenization
* Stemming using PorterStemmer

This helped reduce variations of similar words and improved feature consistency.

---

### 5. Feature Vectorization

The processed text was converted into numerical vectors using **CountVectorizer**.

* Maximum Features: **5000**
* English stop words were removed to improve the quality of the feature vectors.

---

### 6. Similarity Calculation

Cosine Similarity was used to measure the similarity between movie vectors.

Movies with the highest similarity scores are recommended to the user.

The recommendations are generated by comparing the cosine similarity between movie feature vectors.
